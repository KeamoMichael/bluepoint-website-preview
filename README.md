## 3. Stylesheets & Scripts

- **`styles.css`**: Core design system, CSS variables, Figtree typography, reset, header/footer layout.
- **`cinematic-polish.css`**: Cinematic hero treatments, glassmorphic navigation transitions, gold accenting, and motion states.
- **`inner-pages.css`**: Photographic hero headers, editorial grids, and responsive section layouts for all inner pages.
- **`business-content.css`**: Expanded 4-discipline grid, credentials ticker, and corporate profile alignment.
- **`cinematic-nav.js`**: Header scroll-spy script that adapts the dark hero bar into a solid white header upon scrolling.
- **`cinematic-menu.js`**: Responsive mobile drawer menu with keyboard navigation (Esc to close) and accessibility attributes.
- **`cinematic-motion.js`**: Intersection Observer reveal animations with reduced-motion fallback support.
